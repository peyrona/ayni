Message

Tells the user something. Its only button is Close, so it sits in the title row at the right.

Settings, applied at once

No Accept or Cancel. Each change takes effect as soon as it is made, here on this gallery.

Applied on close

The new name is applied when the dialog closes, by the Close button or Esc. An invalid name is not applied, and the status bar says why.

Confirmation

Used only when a change can't be applied live, like a deletion. It needs more than Close, so its buttons go in a bottom row. Keep (also Esc) is the default, and Delete is never the default.

Modeless dialog

Stays open while you keep working, with no backdrop. It has more than Close, so its buttons go in the bottom row: Close and Find next at the right, the extra action (List all matches) at the left.

Dialog rules

Esc always closes a dialog. Avoid Accept and Cancel wherever possible: apply changes as they happen, or when the dialog closes. With Close as the only button, it goes at the right of the title row. Otherwise all buttons, Close included, go in a bottom row: the usual ones (Close, Accept, Cancel) at the right, any extra actions at the left. Enter anywhere in a Panel runs its default (filled) button, except in a text area, on another button, or while a list or menu is open.

States

Every control shares one look per state. In a dialog the default button can be disabled until the input is valid: it stays filled but faded, can still be focused, and its tooltip says why.

Push buttons

Always round with an icon and no label. The tooltip names the action. The filled background marks only the default button (one per view, run by Enter). Meaning goes in the icon colour: red for danger, green for success, amber for warning. A danger button is never the default. A disabled button is faded and does nothing, but it can still be focused and its tooltip says why (see Paste). While an action runs, the button is busy: a spinner replaces the icon and clicks are ignored (try Save).

Toggles

A switch takes effect at once. A toggle button holds an on/off state.

Switch as two radio buttons

A label on each side: the thumb points at the chosen option, so neither side means "off". It does the same job as two radio buttons. Click a label or the track, press Space to flip, or Left and Right to pick a side. Both controls below hold the same value.

Switch as a check box

One label: the switch is on or off. It does the same job as one check box, and it takes effect at once. Click it or press Space. Both controls below hold the same value.

Popup buttons

A small down-pointing triangle means the button opens a menu or popup, like a combo box. These buttons never have a second action, so they never show the dot.

Second action

A dot means the button also takes a double-click, or a long tap on touch screens (Shift+Enter on the keyboard). The tooltip names both actions. A single click waits a quarter of a second, in case a second click follows; a double-click runs only the second action. Buttons without a dot never wait, and a tap or Enter acts at once. Save has no second action, so no dot. A button that opens a popup (menu, popover or dialog) never has a second action.

Turn on Touch preview at the top to try the long tap with the mouse.

States

Disabled is faded and does nothing. Read-only has no border and a soft tint: you see the value but cannot change it. An error puts the Danger colour on the group border and a red "!" next to its label; the message pops up while the focus is in the group, or on hovering or clicking the "!".

Text field

Help goes in the placeholder, not under the field. Nothing appears under the field, errors included: an error colours the border and shows a small red "!" at the end of the field, and its message (how to fix it) pops up while the field has focus, or on hovering or clicking the "!". When the form is sent with errors, the focus goes to the first wrong field, so its message shows. Buttons can sit inside the field, at the start or the end. A read-only field (Customer ID) has no border and a soft tint: you can focus it, select and copy its text, but not change it. A disabled field (Promo code) is faded and can't be focused.

Text area

Multi-line text. When there is a limit, the count sits on the bottom border, near the right end, as a small rounded tag on a solid background.

Search field

Filters as you type. The magnifier sits at the right edge. An optional filter button sits just before it, and a clear button appears once there is text. The first Esc clears the field; a second Esc closes the popup or dialog it sits in, like View options in the Menus tab.

Spin button

A number in a range. Arrow keys or the buttons inside the field step it; holding a button repeats, slowly then faster. Page Up and Page Down step 10 times, Home and End go to the limits. A value out of range shows an error (red border and "!") instead of being corrected. Both "," and "." work as the decimal mark.

Menu bar with pull-down menus

F10 focuses the bar. Left and Right move between menus, Down opens one.

Pop-up menu

Right-click, Shift+F10 or the Menu key opens actions for what is under the pointer. On touch screens a long tap does the same: the ring fills while you hold, and the menu opens when you lift. It also works on the files list and the folder tree in the Lists tab.

Popup with controls

A popup can hold any control: text fields, radio buttons, switches, sliders, lists. Changes apply as you make them. When the content is taller or wider than the popup, it scrolls. Esc or a click outside closes it.

Toolbar

One Tab stop. Arrow keys move between tools.

States

A disabled menu item (Redo, in the Edit menu) is faded and the arrow keys skip it. A disabled toolbar button is faded but keeps its tooltip, which says why.

Tooltips

Appear after half a second of hover, or at once on keyboard focus. Esc hides them. They never hold the only copy of important text. On touch screens there are no tooltips: the Help button at the top opens a dialog that lists every element of the view with its tooltip and a short explanation (turn on Touch preview to try it).

Notifications

Appear bottom-right and leave after 6 seconds (paused while the pointer is on them). Errors stay until dismissed. Every notification has a round close button. One with Undo also says that Ctrl+Z (⌘Z on Mac) undoes, and the shortcut still works after the notification has gone.

Status bar

The strip along the bottom of this Panel. It shows the last action, the selection and where you are.
